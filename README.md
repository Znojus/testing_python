This is a automated testing system for Python programming assignments. In order to successfully run the system, please follow these steps:

1. Make sure Docker desktop (or Docker) is installed on your device and running
2. Make sure Python (at least 3.12) is installed on your device
3. Create a virtual environment (python -m venv venv)
4. Activate venv
5. Install the provided packages in the requirements.txt (pip install -r requirements.txt)
